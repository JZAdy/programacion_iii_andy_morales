## Descripción

Este repositorio contiene las prácticas, ejercicios y proyectos desarrollados durante la materia **Programación III**.

Durante el curso se estudiarán diferentes tecnologías y conceptos relacionados con el desarrollo web, desde los fundamentos de HTML y CSS hasta el desarrollo de aplicaciones frontend y backend utilizando ReactJS, NestJS y TypeScript.

---

## Conceptos y tecnologías

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de las páginas web.

Se aprenderá sobre:

- Estructura de documentos HTML
- Etiquetas y elementos
- Formularios
- Enlaces
- Imágenes
- Tablas
- Elementos semánticos

### CSS

**CSS (Cascading Style Sheets)** permite definir el diseño y la apariencia de las páginas web.

Se aprenderá sobre:

- Selectores
- Colores y fuentes
- Márgenes y padding
- Flexbox
- CSS Grid
- Diseño responsive
- Animaciones y transiciones

### JavaScript

**JavaScript** es un lenguaje de programación utilizado para agregar lógica e interactividad a las aplicaciones web.

Se aprenderá sobre:

- Variables y constantes
- Funciones
- Arreglos y objetos
- Condicionales y ciclos
- DOM
- Eventos
- Promesas
- `async/await`
- Consumo de APIs

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que agrega tipado estático y características adicionales para desarrollar aplicaciones más robustas y mantenibles.

Se aprenderá sobre:

- Tipos de datos
- Interfaces
- Clases
- Funciones tipadas
- Tipos personalizados
- Genéricos
- Programación orientada a objetos

### NestJS

**NestJS** es un framework para desarrollar aplicaciones backend utilizando Node.js y TypeScript.

Se aprenderá sobre:

- Módulos
- Controladores
- Servicios
- Inyección de dependencias
- APIs REST
- DTOs
- Validaciones
- Manejo de excepciones
- Conexión con bases de datos

### ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para crear interfaces de usuario mediante componentes reutilizables.

Se aprenderá sobre:

- Componentes
- JSX
- Props
- Estado
- Hooks
- Eventos
- Formularios
- Consumo de APIs
- Renderizado dinámico
- Componentes reutilizables
