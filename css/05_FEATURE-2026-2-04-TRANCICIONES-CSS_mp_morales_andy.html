Responsive y transiciones CSS

Comandos utilizados

git switch -c FEATURE-2026-2-04-TRANCICIONES-CSS
git add css
git commit -m "feat(2026-10-28): responsive and transitions"

Media query

@media (max-width: 768px) {
  .contenedor {
    flex-direction: column;
  }
}

Transición

.boton {
  transition: background-color 0.3s ease,
              transform 0.3s ease;
}

.boton:hover {
  background-color: #555;
  transform: scale(1.05);
}
